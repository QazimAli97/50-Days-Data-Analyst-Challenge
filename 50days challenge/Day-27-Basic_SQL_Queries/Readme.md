# Day 27 – Basic SQL Queries (SELECT, WHERE, ORDER BY)

## Objective
Use basic SQL clauses to filter, sort, and extract meaningful
business insights from transactional sales data.

## Concepts Covered
- SELECT specific columns
- WHERE filtering
- AND / OR conditions
- ORDER BY for ranking
- BETWEEN, IN, LIKE operators
- Multi-table joins

## Business Questions Answered
- Which orders generate high sales?
- Which orders have low or no profit?
- Which regions contribute specific orders?
- Which customers and products should be prioritised?

## Tool
- SQL Server (SSMS)
