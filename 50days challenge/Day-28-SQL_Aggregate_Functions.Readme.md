## Day 28 – SQL Aggregate Functions | Business Performance Analysis

### Objective
Analyse overall business performance by summarising transactional data into key metrics using SQL aggregate functions.

### Business Questions Answered
- How is the business performing overall?
- Which customers generate the most revenue and profit?
- Which products drive sales and profitability?
- Which regions perform best?
- Which products have higher average order value?

### SQL Concepts Used
- SUM(), COUNT(), AVG()
- GROUP BY
- INNER JOIN
- ORDER BY
- Business KPI calculations

### Tools
- SQL Server (SSMS)

### Outcome
These queries convert raw sales data into executive-level KPIs, forming the foundation for dashboards and business reporting.
