# Day 31 – Time-Based Business Performance Analysis (SQL)

## Objective
Analyse business performance over time using SQL date functions to identify
trends, seasonality, and changes in revenue behaviour.

## Business Questions Answered
- How is sales and profit performance changing year over year?
- Which months generate the highest sales and profit?
- Are there clear seasonal demand patterns?
- How does average order value vary by month?
- How does order volume change across time?

## SQL Concepts Used
- YEAR()
- MONTH()
- SUM()
- AVG()
- COUNT()
- GROUP BY
- ORDER BY
- ROUND()

## Tools
- SQL Server (SSMS)

## Outcome
This analysis converts transactional sales data into time-based insights,
helping businesses understand seasonal trends, plan inventory and campaigns,
and improve forecasting accuracy.
